# Founder Intelligence Examples

## Example 1: Positioning Pivot

### Input
- Business: AI consultancy for mid-market B2B
- Stage: early revenue
- Decision: narrow to healthcare or stay broad
- Horizon: next 90 days

### Correct Routing
- Drucker
- Godin
- Helmer

### Correct Recommendation Shape
- Narrow the offer to the vertical with the strongest proof and fastest sales motion.
- Biggest risk: overfitting to one client signal.
- 48-hour first step: review last 10 sales conversations and tag repeated buyer language.

## Example 2: Pricing Change

### Input
- Current pricing: $2,000/month retainer
- Decision: move to productized package at $5,000

### Correct Routing
- Helmer
- Buffett/Munger
- Drucker

### What Good Output Looks Like
- Explain what the price says about customer type.
- Name what must become more standardized before price goes up.
- Recommend one test package rather than a full pricing overhaul.

## Example 3: Team Execution Problem

### Input
- 8-person team
- Decision: founder keeps redoing work instead of delegating

### Correct Routing
- Horowitz
- Dalio
- Jobs

### What Good Output Looks Like
- Separate trust problem from process problem.
- Recommend one operating cadence change.
- Define the failure mode if nothing changes.
